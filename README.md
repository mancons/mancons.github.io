## 🏗️ Sobre MANCONS S.A.C.

**MANCONS S.A.C.** es una empresa peruana con sede en **Juliaca, San Román, Puno**, orientada al desarrollo de soluciones integrales en ingeniería civil, construcción, consultoría técnica y estudios de laboratorio.

### Tres Divisiones Estratégicas:
1. **MANCONS Ingeniería y Construcción**:
   - Consultoría técnica y expedientes técnicos integrales (Invierte.pe).
   - Análisis y diseño estructural sismorresistente (RNE E.030 / E.060).
   - Construcción y supervisión de edificaciones, obras de saneamiento y obras civiles.
2. **MANCONS Laboratorios**:
   - Estudios geotécnicos y exploración de calicatas.
   - Ensayos de mecánica de suelos y control de calidad de materiales (ASTM D422, ASTM D4318, ASTM D1557, MTC).
3. **MANCONS Digital / BIM**:
   - Modelado BIM interdisciplinario (Arquitectura, Estructuras, MEP).
   - Aplicaciones especializadas: *MANCONS AR / BIM Viewer*, *MANCONS Bridge Designer (AASHTO LRFD)* y modelos de Machine Learning para vulnerabilidad sísmica.

## ❓ ¿Cómo se ejecuta el proyecto?

- **En tu computadora (Local):** **SÍ**, simplemente haz doble clic sobre el archivo [`index.html`](file:///d:/PAG%20WEB/index.html) y se abrirá al instante en cualquier navegador web.
- **En GitHub (Internet):** **NO** tienes que ejecutar nada. GitHub Pages detecta automáticamente el archivo `index.html` en la raíz del repositorio y lo muestra al público en `https://mancons.github.io/`.

## 🌐 Pasos para Publicar en https://mancons.github.io/

1. En tu cuenta de GitHub, crea un nuevo repositorio llamado exactamente:
   ```text
   mancons.github.io
   ```
2. Asegúrate de marcarlo como **Public**.
3. Sube todos los archivos y carpetas de `D:\PAG WEB`:
   - `index.html`
   - `.nojekyll`
   - `.gitignore`
   - Carpeta `css/`
   - Carpeta `js/`
   - Carpeta `assets/` (con logos, imágenes y videos de MANCONS)
   - Carpeta `.github/`
4. Guarda el commit. En 1-2 minutos tu web estará disponible en vivo en:
   👉 **https://mancons.github.io/**

## 📁 Estructura del Proyecto

```text
├── index.html              # Estructura semántica, accesibilidad y contenido institucional
├── .nojekyll               # Desactiva Jekyll en GitHub Pages (evita bloqueos de assets)
├── .gitignore              # Ignora temporales de sistema y editores
├── package.json            # Metadatos del proyecto y scripts npm
├── README.md               # Dossier y guía de despliegue
├── .github/
│   └── workflows/
│       └── deploy.yml      # Despliegue automatizado con GitHub Actions
├── css/
│   ├── style.css           # Paleta oficial granate/dorado, glassmorphism y layout
│   └── cinematic.css       # Film grain, vúmetros de audio estéreo y scopes técnicos
├── js/
│   ├── main.js             # Controlador, cursor lerp, modal con ficha de ingeniería
│   ├── video-player.js     # Reproductor custom con Dynamic Ambilight
│   ├── audio-ambience.js   # Generador sonoro procedural (Web Audio API)
│   ├── frame-scrubber.js   # Deslizador interactivo Modelo BIM vs. Obra Real
│   ├── particles.js        # Polvo y partículas bokeh en tonos granate y oro
│   └── card-tilt.js        # Efecto 3D de inclinación de tarjetas con reflejo especular
└── assets/
    ├── images/             # Logotipo oficial, emblema, fotos de proyectos y laboratorio
    └── videos/             # Metrajes reales: video de dron en obra y modelado BIM 3D
```
